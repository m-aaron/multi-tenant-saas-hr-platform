# Multi-Tenant SaaS HR Management Platform

A backend-focused portfolio project built to simulate a production-style Software-as-a-Service (SaaS) Human Resource Management (HRM) platform.

## Goal

Build a production-oriented backend system while learning:

* Backend Architecture
* REST API Design
* Authentication & Authorization
* PostgreSQL Database Design
* Multi-Tenancy
* Docker
* Testing
* Deployment
* Professional Development Workflow

---

## Planned Stack

Backend:

* Node.js
* Express.js
* TypeScript

Database:

* PostgreSQL

Infrastructure:

* Docker

Architecture:

* Controller
* Service
* Repository
